# 彩蛋视频放这里

这个目录是「求赞助」胶囊连点五下时放的那段视频的位置，文件名固定为 `egg.mp4`。

**视频本身没有进仓库**（几十兆，塞进 Git 以后谁克隆都不好受）。
官方的发布包里是带着这段视频的，直接下 Releases 里的压缩包就有。

如果你是从源码自己构建：

1. 想要彩蛋：自己丢一个 `egg.mp4` 进这个目录（视频格式随意，系统播放器能放就行）。
2. 不想要彩蛋：什么都不用做，构建照样能过。
   连点五下时会提示「电脑上没找到能放视频的播放器」，别的功能不受影响。

这一条对应 `pubspec.yaml` 里的 `assets/easter_egg/`、
`lib/services/platform_service.dart` 里的 `easterEggAsset`。
